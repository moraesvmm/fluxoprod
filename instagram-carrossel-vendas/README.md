# FLUXO ERP - Instagram Carousel (Módulo Vendas)

Este carrossel foi desenvolvido com foco em alta performance visual e marketing digital agressivo para SaaS B2B.

## Estrutura do Design
- **Slide 1 (Capa):** PDV / Transactional - Foco na atomicidade da transação.
- **Slide 2 (Problema):** Venda Confirmada / Estoque Quebrado - Identificação da dor do cliente.
- **Slide 3 (Solução):** Fluxo Atômico - Como o sistema resolve a inconsistência em tempo real.
- **Slide 4 (Funcionalidades):** Grid de recursos principais do módulo.
- **Slide 5 (CTA):** Chamada para ação com prova social/técnica (Uptime, Segurança).

## Especificações Técnicas
- **Resolução:** 1080x1080px por slide.
- **Cores:** Violet/Indigo Gradient sobre Fundo Preto Puro (#000).
- **Tipografia:** Space Grotesk (Títulos) e Inter (Textos).
- **Efeitos:** Backdrop-filter (blur), Sombras intensas, Animação conic-gradient.

## Como Exportar
1. Abra o arquivo `carrossel.html` no navegador (preferencialmente Chrome/Edge).
2. Utilize uma ferramenta de captura de tela ou extensão de "Full Page Screenshot".
3. Certifique-se de que o zoom do navegador está em 100%.
4. Recorte cada bloco de 1080x1080px (os slides estão empilhados verticalmente).

## Tecnologias Utilizadas
- HTML5 / CSS3 (Modern features like conic-gradient and backdrop-filter).
- Lucide Icons (SVG Inline).
- Google Fonts (Space Grotesk & Inter).
